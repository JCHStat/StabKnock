# Data directory

The empirical analyses expect a private file named `data.xlsx` in this
directory. The dataset is not distributed with this repository.

Required format:

- Excel workbook (`.xlsx`), with the analysis data on the first worksheet.
- 27 columns, in the order documented in the repository's main README.
- 13,128 rows for the stage-specific analysis (2,965 from 2010; 3,653 from
  2014; 3,712 from 2018; and 2,798 from 2020).

Do not commit the dataset. The repository's `.gitignore` excludes all files in
this directory except this documentation file.
